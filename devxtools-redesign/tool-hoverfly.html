Hoverfly

Service virtualization and API simulation with record/replay and templating.

Website Repository

Overview

Lightweight service virtualization tool built in Go. Capture and simulate APIs with request matching, templating, and stateful behavior.

When to use it

When you need to virtualize downstream services with record/replay, run them as a single Go binary or Docker container, and keep simulations stateful across requests.

Details

Record & replay

Capture real traffic once, then simulate it offline.

Request matching

Match on method, path, headers, query and body.

Templating

Dynamic responses built from request data.

Stateful behavior

Model multi-step flows that change over time.

Quick start

# run Hoverfly in Docker
docker run -d -p 8888:8888 -p 8500:8500 spectolabs/hoverfly
# switch to capture mode
hoverctl mode capture
