# MSW + Vitest Demo

This demo shows how to mock API calls with MSW (Mock Service Worker) in Vitest tests.

## Run it

```bash
npm install
npm test
```

## What it demonstrates

- Setting up MSW server for Node.js tests
- Mocking HTTP requests with handlers
- Overriding handlers per test
- Error handling

## Packages

- `msw` 3.0.3
- `vitest` 5.0.5
