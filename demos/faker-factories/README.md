# Faker.js Test Data Factories Demo

This demo shows how to create deterministic test data factories with Faker.js.

## Run it

```bash
npm install
npm test
```

## What it demonstrates

- Seeding Faker for deterministic data
- Setting a reference date for relative dates
- Creating factory functions with sensible defaults
- Overriding specific fields per test
- Creating multiple objects at once

## Packages

- `@faker-js/faker` 10.6.0
- `vitest` 5.0.5
